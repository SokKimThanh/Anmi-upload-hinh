## 3. Hướng dẫn An toàn và Ghi chú

### Hướng dẫn Vận hành An toàn (Trang 21)

1.  Vui lòng chọn **tốc độ quay phù hợp theo khuyến nghị** trước khi mài.
2.  Chọn mũi mài carbide phù hợp về **hình dạng, đường kính và loại răng** cho các kiểu gia công khác nhau.
3.  Đảm bảo phần **chuôi của mũi mài và đầu kẹp của máy mài được kết nối chắc chắn** trước khi sử dụng.
4.  **Không đặt quá nhiều áp lực** lên mũi mài khi mài (sẽ làm tăng nhiệt độ và rút ngắn tuổi thọ).
5.  **Không tiếp tục quay khi mũi mài bị kẹt** trong rãnh hoặc khe của vật liệu.
6.  **Không sử dụng mũi mài trong môi trường có nhiều khí dễ cháy**.

### Ghi nhận Dữ liệu Thống kê

* **Tốc độ quay (RPM):** Tài liệu có đề cập khuyến nghị chọn tốc độ quay nhưng **không cung cấp số liệu cụ thể** (cần tra cứu bảng chi tiết).
* **Kích thước (D-L-d):** Các bảng chi tiết kích thước (Metric/Inch Size) tồn tại cho từng loại burr (A $\rightarrow$ N), nhưng không được trích xuất thành số liệu cụ thể trong ngữ cảnh này.
* **Mâu thuẫn văn bản:** Mô tả tiếng Việt cho **Type J** có ghi "Khoan chóp $90^{\circ}$", mâu thuẫn với tên tiếng Anh và ứng dụng $60^{\circ}$.Để làm rõ ngữ cảnh về việc chuẩn hóa SEO (Search Engine Optimization) cho các bài viết được xây dựng dựa trên tài liệu **“Carbider Burr.pdf”**, tôi bổ sung phần đánh giá chiến lược nội dung.

```php
add_filter( 'rank_math/snippet/rich_snippet_product_entity', function( $entity ) {

    $entity['manufacturer'] = [

    $entity['additionalProperty'] = [];
    
    // Kiểu cắt
    $cut_type = get_post_meta( $product_id, '_pa_kieu-cat', true );
    if ( $cut_type ) {

            '@type' => 'PropertyValue',
            'name'  => 'Kiểu Cắt',
```

### K. Mobile-First Optimization - Typography & Image Styles

**⚠️ QUAN TRỌNG: Đơn vị đo lường tốt nhất**

**Tại sao dùng `rem` thay vì `px`:**
- ✅ **Accessibility**: Tôn trọng thiết lập font-size của người dùng (WCAG AA/AAA)
- ✅ **Responsive**: Dễ scale toàn bộ typography bằng cách thay đổi `html { font-size }`
- ✅ **Consistency**: 1rem luôn bằng font-size của `<html>` (mặc định 16px)
- ✅ **SEO**: Google ưu tiên websites có accessibility tốt
- ❌ **px**: Cứng nhắc, không thân thiện với người khiếm thị dùng screen reader

**Quy đổi rem sang px (base 16px):**
- 0.875rem = 14px (mobile body text)
- 1rem = 16px (desktop body text)
- 1.5rem = 24px (mobile h1)
- 2rem = 32px (desktop h1)
- 2.25rem = 36px (large desktop h1)

**Responsive Font Sizes (Mobile First - Sử dụng rem):**

#### **3. Custom Breadcrumbs for Products (Rank Math)**

```php
// Custom product breadcrumbs cho Rank Math
add_filter( 'rank_math/frontend/breadcrumb/items', 'anmi_custom_rankmath_breadcrumbs' );
function anmi_custom_rankmath_breadcrumbs( $crumbs ) {
    if ( is_singular( 'product' ) ) {
        global $post;
        
        // Xóa breadcrumb mặc định của WooCommerce nếu có
        foreach ( $crumbs as $key => $crumb ) {
            if ( isset( $crumb[1] ) && strpos( $crumb[1], 'shop' ) !== false ) {
                unset( $crumbs[ $key ] );
            }
        }
        
        // Tạo lại breadcrumb
        $new_crumbs = [];
        $new_crumbs[] = $crumbs[0]; // Giữ Home
        
        // Thêm "Carbide Burr" hub page
        $new_crumbs[] = [
            'Carbide Burr',
            home_url( '/carbide-burr/' )
        ];
        
        // Lấy category chính của product
        $terms = get_the_terms( $post->ID, 'product_cat' );
        if ( $terms && ! is_wp_error( $terms ) ) {
            // Lọc bỏ category cha "Carbide Burr" nếu trùng
            $filtered_terms = array_filter( $terms, function( $term ) {
                return $term->slug !== 'carbide-burr';
            });
            
            if ( ! empty( $filtered_terms ) ) {
                $main_term = array_shift( $filtered_terms );
                
                // Thêm parent categories nếu có
                if ( $main_term->parent ) {
                    $parent_term = get_term( $main_term->parent, 'product_cat' );
                    $new_crumbs[] = [
                        $parent_term->name,
                        get_term_link( $parent_term )
                    ];
                }
                
                // Thêm category chính
                $new_crumbs[] = [
                    $main_term->name,
                    get_term_link( $main_term )
                ];
            }
        }
        
        // Thêm product title (không có link)
        $new_crumbs[] = [
            get_the_title()
        ];
        
        return $new_crumbs;
    }
    
    return $crumbs;
}
```

```php
// Custom sitemap priority và frequency cho products
add_filter( 'rank_math/sitemap/entry', 'anmi_custom_rankmath_sitemap', 10, 3 );
function anmi_custom_rankmath_sitemap( $url, $type, $object ) {
    
    // Chỉ áp dụng cho products
    if ( 'product' !== $type ) {
        return $url;
    }
    
    // Ưu tiên mặc định cho products
    $url['priority'] = 0.8;
    $url['changefreq'] = 'monthly';
    
    // Bài viết tổng quan (file 01-03) có priority cao nhất
    $overview_slugs = [
        'carbide-burr-la-gi',
        'so-sanh-cac-loai-carbide-burr',
        'huong-dan-chon-carbide-burr'
    ];
    
    if ( in_array( $object->post_name, $overview_slugs ) ) {
        $url['priority'] = 1.0;
        $url['changefreq'] = 'weekly';
    }
    
    // Bài viết kiểu cắt (file 04-10) có priority trung bình cao
    $cut_type_slugs = [
        'double-cut-carbide-burr',
        'single-cut-carbide-burr',
        'aluminium-cut-carbide-burr',
        'fine-cut-carbide-burr',
        'diamond-cut-carbide-burr',
        'coarse-cut-carbide-burr',
        'chip-breaker-cut-carbide-burr'
    ];
    
    if ( in_array( $object->post_name, $cut_type_slugs ) ) {
        $url['priority'] = 0.9;
        $url['changefreq'] = 'monthly';
    }
    
    // Sản phẩm mới (< 30 ngày) có changefreq cao hơn
    $post_date = strtotime( $object->post_date );
    $days_old = ( time() - $post_date ) / DAY_IN_SECONDS;
    
    if ( $days_old < 30 ) {
        $url['changefreq'] = 'weekly';
    }
    
    return $url;
}

// Thêm lastmod date chính xác
add_filter( 'rank_math/sitemap/entry', 'anmi_custom_rankmath_lastmod', 11, 3 );
function anmi_custom_rankmath_lastmod( $url, $type, $object ) {
    if ( 'product' === $type ) {
        // Sử dụng modified date thay vì publish date
        $url['mod'] = mysql2date( 'Y-m-d\TH:i:s+00:00', $object->post_modified_gmt, false );
    }
    
    return $url;
}
```

## 13. Style Guide & Code Standards - Quy Chuẩn Thống Nhất

### A. Nguyên tắc Chung khi Generate Code

**🎯 MỤC TIÊU:** Đảm bảo tất cả 28 bài viết SEO có style nhất quán, dễ maintain, và tuân thủ best practices.

**📌 NGUYÊN TẮC CỐT LÕI:**
1. **Consistency First**: Tất cả code phải follow cùng một pattern
2. **Accessibility Mandatory**: WCAG AA minimum, hướng đến AAA
3. **Mobile-First Always**: Design cho mobile trước, desktop sau
4. **Performance Optimized**: Core Web Vitals là ưu tiên hàng đầu
5. **SEO-Driven**: Mọi quyết định code phải có lý do SEO rõ ràng

### A1. Human-Centered Writing (Giọng văn giàu tính người)

**MỤC TIÊU:** Nội dung không chỉ “chuẩn SEO” mà còn tạo sự tin cậy, cảm giác được đồng hành, thân thiện và tôn trọng người đọc trong ngành gia công cơ khí.

**Nguyên tắc giọng văn:**
- Ấm áp – chuyên nghiệp – không phô trương.
- Tránh câu quá “marketing”, ưu tiên tính hữu ích thực tế.
- Viết cho kỹ thuật viên, chủ xưởng, quản lý sản xuất: rõ ràng, không lên lớp.
- Không hứa hẹn quá mức: chỉ nói điều chắc chắn có trong tài liệu.
- Dùng “bạn” và “chúng tôi” khi phù hợp: tạo kết nối.

**Cấu trúc cảm xúc (Emotional Framing) áp dụng ở mở bài & CTA:**
1. Ghi nhận vấn đề: “Bạn đang gặp…”, “Nhiều xưởng gặp khó ở chỗ…”
2. Đồng cảm: “Điều này rất phổ biến khi…”, “Chúng tôi đã gặp nhiều case tương tự…”
3. Trao quyền: “Bạn có thể cải thiện bằng cách…”, “Chỉ cần chọn đúng kiểu cắt…”
4. Hành động nhẹ nhàng: “Nếu cần hỗ trợ thêm, đội ngũ kỹ thuật có thể giúp bạn chọn nhanh.”

**Mẫu câu nên dùng:**
- “Nếu bạn đang…”
- “Một lỗi thường gặp là…”
- “Giải pháp thực tế là…”
- “Bạn không cần cố ép tốc độ – hãy để lưỡi cắt làm việc.”
- “Khi chưa có dữ liệu (RPM, kích thước), tốt nhất đừng phỏng đoán.”

**Mẫu cần hạn chế:** (Tránh robot / bán hàng thô)
- ❌ “Sản phẩm tuyệt vời nhất thị trường”
- ❌ “Cam kết chất lượng số 1”
- ❌ Lặp từ khóa dày đặc chỉ để SEO

**Chèn cảm xúc nhẹ tự nhiên:**
- Sau cảnh báo an toàn: “Điều này không chỉ giúp dụng cụ bền hơn mà còn bảo vệ người thao tác.”
- Sau hướng dẫn chọn: “Nếu bạn vẫn phân vân giữa hai kiểu, cứ ghi chú lại ứng dụng chính – chúng tôi có thể hỗ trợ lọc giúp.”

**Checklist Human Tone trong mỗi bài:**
- [ ] Có 1–2 câu đồng cảm ở phần mở bài.
- [ ] Có 1 đoạn trao quyền giải quyết vấn đề (empowerment).
- [ ] CTA không gây áp lực (“Liên hệ nếu cần thêm”, tránh “MUA NGAY”).
- [ ] Không bịa số liệu – nếu thiếu nói rõ “Chưa có trong tài liệu”.
- [ ] Tối thiểu 1 câu trấn an: “Đây là tình huống rất thường gặp…”

### L. Common Mistakes to AVOID (❌)

1. **❌ Dùng px cho font-size**
   - ✅ Dùng rem để responsive và accessible

2. **❌ Không có alt text cho images**
   - ✅ Mỗi image phải có alt text mô tả chi tiết

3. **❌ Heading không theo thứ tự (H1 → H3 → H2)**
   - ✅ Luôn theo hierarchy: H1 → H2 → H3 → H4

4. **❌ Keyword stuffing (lạm dụng keyword)**
   - ✅ Keyword density 1-2%, tự nhiên trong ngữ cảnh

5. **❌ Không có internal links**
   - ✅ Mỗi bài phải có 3-5 internal links

6. **❌ Meta description quá ngắn (< 120 chars)**
   - ✅ 150-160 characters, có focus keyword và CTA

7. **❌ Images không có width/height attributes**
   - ✅ Luôn thêm width/height để tránh CLS

8. **❌ CSS inline trong HTML**
   - ✅ Tách riêng CSS vào file external

9. **❌ Không test trên mobile**
   - ✅ Mobile first, test trên nhiều devices

10. **❌ Không có Schema markup**
    - ✅ Bắt buộc Product Schema cho tất cả sản phẩm
