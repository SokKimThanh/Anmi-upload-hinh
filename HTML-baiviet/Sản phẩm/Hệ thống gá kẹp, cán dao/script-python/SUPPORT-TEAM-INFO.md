## 🔄 Quy Trình Cập Nhật File Cũ

Nếu phát hiện file còn thông tin cũ:

1. **Tìm kiếm pattern:**
   ```bash
   grep -r "10.*năm.*kinh nghiệm" "seo html/"
   ```

2. **Thay thế thủ công:**
   - Mở file trong editor
   - Find: `10+ năm kinh nghiệm` hoặc `10 năm`
   - Replace: `15+ năm kinh nghiệm`

3. **Test:**
   - Kiểm tra HTML syntax
   - Xem preview trên browser
   - Verify trên WordPress
