Khi nhận lệnh "Viết bài [Sản phẩm] theo style An Mi Tools", phải tuân thủ:

1. XÁC THỰC VÀ AN TOÀN NỘI DUNG
   • Không bao giờ bịa đặt thông số kỹ thuật, nếu không có dữ liệu chính xác, đánh dấu "TBD" và yêu cầu người dùng cung cấp.
   • Trích dẫn nguồn uy tín sau mọi số liệu: `[Nguồn: Wikipedia/Nhà sản xuất]`
   • Tránh ngôn ngữ tuyệt đối ("luôn luôn", "không bao giờ", "tốt nhất thế giới") nếu chưa xác minh
   • Đảm bảo nội dung trung thực, không gây hại, không ảo giác AI hallucination
   • Kiểm tra kỹ các thông số nhiệt độ, độ cứng, tuổi thọ trước khi ghi

2. CẤU TRÚC NỘI DUNG CHUẨN AN MI TOOLS STYLE (8-SECTION TEMPLATE)
   • **Đoạn mở**: 1-2 câu hook về sản phẩm, nhấn mạnh USP chính và target application
   • **H2: Giới thiệu [Tên sản phẩm]**: Định nghĩa, technology background, vị trí trong thị trường
   • **H2: Đặc điểm Nổi bật & Lợi ích Vượt trội**: 3-4 điểm chính dạng numbered list với sub-bullets:
     - Ưu điểm kỹ thuật core (có so sánh số liệu)
     - Performance metrics (tuổi thọ, độ chính xác)  
     - Cost-benefit analysis
     - Unique selling points vs competitors
   • **H2: Thông số Kỹ thuật [Loại vật liệu]**: Bảng HTML 4-layer responsive wrapper
   • **H2: Ứng dụng [Sản phẩm] trong ngành [Target Industry]**: 3-4 use cases cụ thể
   • **H2: Hướng dẫn Sử dụng & Bảo quản**: Numbered list best practices
   • **H2: Vì sao chọn [Sản phẩm] của An Mi Tools?**: Company USPs và guarantees
   • **H2: FAQ (Các câu hỏi thường gặp)**: 2-3 cặp Q&A addressing common objections
   • **H2: Kết luận**: Summary + 2 CTA progression + Brand image

3. ĐỊNH DẠNG VÀ VISUAL HIERARCHY (Dựa trên phân tích bài mẫu)
   
   **3.1 HIERARCHY STRUCTURE:**
   • **H2 ONLY**: Tất cả sections sử dụng H2, KHÔNG dùng H3 để giữ hierarchy đơn giản
   • **H2 naming convention**: "[Action/Category] [Product Name] [Context]" 
   
   **3.2 TYPOGRAPHY & FORMATTING:**
   • **Bold (`<b>`)**: Tên sản phẩm, thuật ngữ kỹ thuật, measurements, key concepts
   • **Italic (`<i>`)**: Technical specifications trong sub-bullets, citations
   • **KaTeX math**: `<span class="math-inline"><span class="katex">...</span></span>` cho units (°C, HRC, μm)
   
   **3.3 KHÔNG GIAN ÂM (White Space Management):**
   • **Paragraph length**: 2-3 câu tối đa, ngắt đoạn thường xuyên
   • **List structure**: Bullet points có sub-bullets với `<ul><li>` nested
   • **Numbered lists**: Sử dụng `<ol start="1">` cho sequential instructions
   
   **3.4 IMAGE SPECIFICATIONS:**
   • **Width cố định**: `width="1000"` cho tất cả images
   • **Height auto**: `height="auto"` hoặc tỷ lệ proportional (VD: 463 cho 1000x463)
   • **Alt text**: Chứa từ khóa chính, mô tả chính xác nội dung
   • **Alignment**: `class="wp-image-[ID] aligncenter"` cho center alignment
   
   **3.5 TABLE RESPONSIVE STRUCTURE** (4-layer wrapper):
   ```html
   <div class="horizontal-scroll-wrapper">
   <div class="table-block-component">  
   <div class="table-block has-export-button">
   <div class="table-content not-end-of-paragraph">
   <table>
   <thead><tr><td>Thông số</td><td>Giá trị</td><td>Ghi chú</td></tr></thead>
   <tbody><tr><td><b>Parameter</b></td><td>Value</td><td>Note</td></tr></tbody>
   </table>
   </div></div></div></div>
   ```

4. SEO VÀ LIÊN KẾT
   • **Internal link**: 1 link đến danh mục sản phẩm với anchor text có từ khóa
   • **External link**: 1 link đến Wikipedia hoặc nguồn uy tín với `target="_blank" rel="noopener"`
   • **Từ khóa chính**: Xuất hiện trong 50 từ đầu, H2, và phân bố tự nhiên 1-2% mật độ
   • **Alt text**: Mô tả hình ảnh chính xác với từ khóa

5. WORDPRESS WOOCOMMERCE COMPATIBILITY
   • Sử dụng HTML tags chuẩn WordPress (h2, b, ul, ol, li)
   • Class CSS tương thích với theme WooCommerce
   • Image URL format: `src="https://anmitools.com/wp-content/uploads/..."`
   • Responsive design cho mobile
   • CTA buttons với định dạng chuẩn

6. CTA PROGRESSION & CONVERSION FLOW
   • **Natural CTA**: External reference link trong section giới thiệu với `target="_blank" rel="noopener"`
   • **Mid-content CTA**: Internal link trong section ứng dụng về related products
   • **Final CTA sequence** (3-part close):
     - **CTA 1**: `<a href="[Category URL]"><b><span class="citation-30">Action-oriented message!</span></b></a>`
     - **CTA 2**: `<b><span class="citation-29">Liên hệ ngay để nhận báo giá chi tiết và tư vấn kỹ thuật chuyên sâu về [Product]!</span></b>`
     - **Brand image**: `<img class="wp-image-[ID] aligncenter" src="https://anmitools.com/wp-content/uploads/[path]" alt="[Alt text]" width="1000" height="463" />`

7. WORDPRESS WOOCOMMERCE TECHNICAL SPECS
   
   **7.1 CSS ORGANIZATION (BẮT BUỘC):**
   • **KHÔNG sử dụng inline styles**: Tuyệt đối không viết `style="..."` trên các thẻ HTML
   • **CSS Block ở đầu bài**: Tất cả styles phải được gom trong `<style>` block đặt ở TOP của bài viết
   • **Structure pattern**:
     ```html
     <style>
     .custom-class { 
         property: value; 
     }
     .another-class {
         property: value;
     }
     </style>
     
     [Nội dung bài viết HTML...]
     ```
   • **WooCommerce compatibility**: Styles được tổ chức trong block giúp hệ thống WooCommerce dễ parse và cache
   
   **7.2 TECHNICAL IMPLEMENTATION:**
   • **Image path format**: `https://anmitools.com/wp-content/uploads/YYYY/MM/filename.webp`
   • **CSS classes**: `wp-image-[ID]`, `aligncenter`, `math-inline`, `katex`, responsive table wrappers
   • **Citation spans**: `<span class="citation-[number]">` cho tracking CTA performance
   • **Links**: Internal absolute paths, external với proper attributes
   • **Mobile-first**: Responsive tables, scalable images, readable typography
