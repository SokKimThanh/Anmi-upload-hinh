### Technical Notes - Morse Taper Specifics

**Run-out specification**: 0.005mm (higher tolerance than HGER's 0.003mm)
- Morse taper systems typically have slightly higher run-out due to the taper interface
- Still acceptable for milling and reaming operations
- Drawbar mechanism compensates with strong axial force

**Key differentiator vs MTA**:
- **MTB (Drawbar/Nut Type)**: Internal bolt pulls tool into holder via thread
- **MTA (Tang Drive Type)**: Uses flat tang drive mechanism
- MTB is safer for milling operations (no risk of tool ejection under vibration)

## 🔍 Lessons Learned

### 1. **Always Verify Against Official Documentation**
- User-provided "Tổng hợp mã Insert và Holder.txt" is authoritative source
- Technical specs must match exactly (RPM, clamping ranges, model codes)
- Marketing content can be flexible, but specs cannot

### 2. **HGER vs GER Distinction is Critical**
- Both achieve same run-out (0.003mm)
- Difference: Dynamic balance grade (G2.5 vs G6.3), material hardness, lifespan
- HGER maintains precision longer at high speeds
- This context was missing and has been added

### 3. **Model Code Accuracy Matters**
- "BT-HGER HGER16" doesn't exist in catalog
- Correct format: "BT40-HGER25" or "BT30-GER16"
- Pattern: BT[size]-[series][collet_size]

### 4. **RPM Varies by Collet Size**
- Larger collet → lower max RPM (due to mass/centrifugal force)
- BT40-HGER25 (ER25): 25,000 RPM
- BT40-HGER32 (ER32): 20,000 RPM
- This relationship should be explained in installation guide

### 5. **Consistency in SEO Pattern**
- Primary keyword: Title Case (not lowercase)
- H1: Clean, focused, matches primary keyword exactly
- First H2: "Tổng Quan [Product Name] – [Key Feature]"
- Subsequent H2s: Include full product name for keyword density
- SEO Description: Start with "Mua", include key specs (run-out, RPM, applications)
