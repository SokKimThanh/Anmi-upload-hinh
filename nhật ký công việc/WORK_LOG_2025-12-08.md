## 2. Lessons Learned & Best Practices Applied

### 2.1. SEO Optimization Pattern
1. **Capitalization consistency**: Primary keyword MUST match seo_title exactly
2. **Rel attribute**: Use `rel="noopener"` only, avoid `noreferrer`
3. **H1/H2 strategy**: Include full product name with insert codes
4. **External links**: Wikipedia link to Cemented Carbide in applications section
5. **Image naming**: Sequential numbering with descriptive suffixes

### 2.2. Batching Strategy
- **Backend batches**: Metadata → Content → External links
- **Frontend batches**: Structure → Insert images → Holder images → Applications → JSON-LD
- **Commit granularity**: One commit per major batch for easy rollback

### 2.3. Technical Accuracy
- Always cross-reference with `milling_knowledge.md`
- Verify holder codes match catalog exactly
- Check KAPR, APMX, DC ranges for consistency
- Validate material group indicators (P/M/K/N/S/H)
